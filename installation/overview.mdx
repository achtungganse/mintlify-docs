До установки осталось совсем немного. Убедись, что телефон готов к eSIM, подключись к интернету и открой данные для установки — дальше можно переходить к инструкции для своего устройства.

## Перед началом

<Note>
  **Понадобятся четыре вещи:**

  - **Телефон с поддержкой eSIM.** Проверь свою модель по [списку совместимых устройств](/getting-started/compatible-devices).
  - **Разблокированный телефон.** Устройство, привязанное к одному оператору, может не принять другую eSIM. [Как проверить блокировку →](/getting-started/check-carrier-lock)
  - **Подключение к интернету.** Во время добавления eSIM телефон загружает её профиль. Если есть возможность, используй стабильный Wi-Fi.
  - **Данные для установки.** Это может быть QR-код или данные для ручного добавления eSIM.
</Note>

## Один момент перед установкой

Если eSIM куплена заранее, посмотри, **когда начинает действовать тариф**.

У одной eSIM отсчёт может начаться после подключения к сети назначения, у другой условия будут отличаться. Это стоит узнать до установки, а не после.
