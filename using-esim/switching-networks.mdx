---

Главное преимущество телефона с двумя SIM: не нужно выбирать между доступностью и экономией на данных. Большинство современных смартфонов позволяют работать с домашней SIM и eBanano eSIM одновременно: ваш обычный номер принимает звонки и SMS как обычно, а eBanano берет на себя все мобильные данные. Лучшее из двух миров, без лишних хлопот.

## Назначьте eBanano основной SIM для данных

Ключевой шаг: сказать телефону использовать eBanano для данных. Вот как это сделать на популярных устройствах:

<Tabs>
  <Tab title="iPhone">
    1. Откройте **Settings** и нажмите **Cellular** (Настройки → Сотовая связь).
    2. Нажмите **Cellular Data** (Сотовые данные).
    3. В списке выберите линию **eBanano eSIM**.
    4. Вернитесь в **Cellular** (Сотовая связь), нажмите на линию eBanano и убедитесь, что **Data Roaming** (Роуминг данных) включен.

    Готово! Теперь iPhone направляет все мобильные данные через eBanano, а домашняя SIM остается доступной для звонков и SMS.
  </Tab>
  <Tab title="Android (Samsung)">
    1. Откройте **Settings** и нажмите **Connections** (Настройки → Подключения).
    2. Нажмите **SIM Manager** (Диспетчер SIM).
    3. В разделе **Mobile Data** (Мобильные данные) выберите **eBanano eSIM**.
    4. Подтвердите переключение, если появится запрос.

    Samsung может спросить, хотите ли вы сменить сеть данных: нажмите **OK**, чтобы подтвердить eBanano в качестве SIM для данных.
  </Tab>
  <Tab title="Android (Pixel)">
    1. Откройте **Settings** и нажмите **Network & Internet** (Настройки → Сеть и интернет).
    2. Нажмите **SIMs** (SIM-карты).
    3. В разделе **Preferred SIM for Data** (Предпочтительная SIM для данных) выберите **eBanano eSIM**.

    Теперь Pixel использует eBanano для мобильных данных. Другая SIM остается активной для звонков и сообщений.
  </Tab>
</Tabs>

<Tip>
  Оставляйте домашнюю SIM активной для звонков и SMS за границей: друзья и семья по-прежнему могут дозвониться на ваш обычный номер. Главное, чтобы eBanano была назначена основной для данных, и можно отправляться в путь!
</Tip>

<Warning>
  Если у вас есть физическая SIM из другой страны (например, местная SIM с прошлой поездки), обязательно отключите для нее мобильные данные. Если она назначена SIM для данных, телефон может подключиться через нее и начислить неожиданные роуминговые сборы. Проверяйте настройку SIM для данных каждый раз, когда меняете физическую SIM.
</Warning>

## Переключение обратно по возвращении домой

Когда вы вернулись из поездки, переключите данные обратно на домашнюю SIM, чтобы не расходовать eBanano тариф дома.

Просто повторите шаги выше, но на этот раз выберите **домашнюю SIM** в качестве предпочтительной линии для данных. eBanano eSIM останется сохраненной на телефоне: готовой к следующему приключению, но не будет использовать данные, пока вы снова не переключитесь на нее.

Можно также полностью отключить линию eBanano eSIM, чтобы навести порядок:
- **iPhone:** Settings → Cellular → нажмите на линию eBanano → переключите **Turn On This Line** (Включить эту линию) в выкл.
- **Android:** Settings → Connections → SIM Manager → выключите eBanano eSIM.

eSIM-профиль остается на устройстве. Вы можете включить его в любой момент.
