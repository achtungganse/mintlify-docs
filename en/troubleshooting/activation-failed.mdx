Hitting an error during activation is frustrating — especially when you're eager to get connected before your trip. The good news is that activation failures almost always come down to one of a small handful of causes, each with a straightforward fix. This guide walks you through every common scenario so you can get your eSIM up and running without the headache.

<Warning>
  Do **not** attempt to scan the QR code multiple times if your first attempt failed. Repeated scans can flag the code as used and make recovery more complicated. If activation didn't go smoothly, follow the steps below or contact support — we'll get you sorted.
</Warning>

## Common Activation Error Causes

Recognise your situation in one of these? Jump straight to the matching fix in the accordion below.

<Accordion title="QR Code Already Used">
  Each eBanano QR code is single-use and tied to one device. If the code has been scanned before — even unsuccessfully on another phone — it may be marked as used and will need to be replaced by our support team. See the fix below for what to do next.
</Accordion>

<Accordion title="Poor Wi-Fi During Installation">
  Downloading an eSIM profile requires a stable internet connection. A dropped or slow Wi-Fi signal mid-installation can interrupt the process and leave the activation in a broken state. See the fix below for how to retry successfully.
</Accordion>

<Accordion title="Device Carrier Lock">
  If your phone is locked to your home carrier, it may refuse to install an eSIM profile from a different network. This is one of the most common activation blockers for travelers. See the fix below, or visit the [Device Compatibility guide](/en/troubleshooting/device-compatibility) for full details.
</Accordion>

<Accordion title="Incorrect Date / Time Settings">
  eSIM profiles use time-sensitive security certificates. If your phone's date or time is significantly off, the certificate check will fail and activation will be rejected. The General Recovery Steps section below explains how to fix this quickly.
</Accordion>

## Fixing Each Issue

<Accordion title="QR code already used error">
  Each QR code can only be scanned once, on one device. If you see an "already used" or "activation code already redeemed" error, the code is no longer valid for fresh installation.

  **What to do:**

  - Do not scan the code again — it won't help.
  - [Contact eBanano Support](/en/about/contact-support) with your order number and explain that your QR code has been flagged as used.
  - Our team will verify your order and issue a replacement activation code promptly.
</Accordion>

<Accordion title="Installation failed / couldn't download profile">
  This usually happens when your Wi-Fi drops or slows down mid-download, or when a VPN interferes with the secure connection to the eSIM server.

  **What to do:**

  1. Disconnect from any VPN you have running.
  2. Move closer to your Wi-Fi router or switch to a more reliable network.
  3. Restart your phone.
  4. Try the installation again from **Settings → Cellular / Mobile Data → Add eSIM / Add Data Plan**.
  5. If the same QR code fails repeatedly, contact support — it may need to be reissued.
</Accordion>

<Accordion title="Not supported by carrier or Profile installation failed">
  This error almost always means your phone is **carrier-locked** — it's been restricted by your home carrier to only work with their own SIM or eSIM profiles.

  **What to do:**

  1. Contact your current carrier (the one your phone's main SIM belongs to) and ask them to **unlock your device**.
  2. Most carriers will unlock a phone that has completed its contract or is fully paid off — sometimes just by asking.
  3. Once unlocked, try the eBanano installation again.
  4. See the [Device Compatibility guide](/en/troubleshooting/device-compatibility) for more detail on carrier locks.
</Accordion>

<Accordion title="The activation code is invalid error">
  This can happen if the QR code was scanned at an angle or in poor lighting, resulting in a misread. It can also happen if you're trying to use a QR code meant for a different device type.

  **What to do:**

  1. Try scanning again in good lighting, holding the camera steady and centred on the QR code.
  2. Alternatively, use **manual entry**: most phones offer an "Enter details manually" option during eSIM setup. Your eBanano confirmation email includes the activation code as a text string — enter it exactly as shown.
  3. Double-check you're using the QR code from your most recent eBanano order confirmation email.
  4. If the code still fails, [contact eBanano Support](/en/about/contact-support) for a fresh one.
</Accordion>

## General Recovery Steps

If you're not sure which error applies to you, or you want to start fresh, follow these steps in order:

<Steps>
  <Step title="Check your Wi-Fi connection">
    Make sure you're on a stable, fast Wi-Fi network. Disconnect from any VPN. Avoid public hotspots if possible — home or hotel Wi-Fi works best.
  </Step>
  <Step title="Verify your phone's date and time">
    Go to **Settings → General → Date & Time** (iPhone) or **Settings → General Management → Date and Time** (Android) and enable **Set Automatically**. This ensures your device clock is accurate and won't fail certificate checks.
  </Step>
  <Step title="Restart your phone">
    A full restart clears any cached errors from a previous failed attempt. Shut down completely, wait 15 seconds, then power back on.
  </Step>
  <Step title="Try the activation again">
    Return to **Settings → Cellular / Mobile Data → Add eSIM** and scan your QR code (or enter the code manually). Take your time — make sure the camera reads the code cleanly.
  </Step>
  <Step title="Contact support if still failing">
    If you've made it through all four steps and activation still fails, don't keep trying solo. [Reach out to eBanano Support](/en/about/contact-support) with your order number and describe the exact error message you're seeing. We'll take it from there.
  </Step>
</Steps>
